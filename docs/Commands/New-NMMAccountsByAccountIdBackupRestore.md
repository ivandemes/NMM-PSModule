# New-NMMAccountsByAccountIdBackupRestore

## Synopsis

## Syntax

~~~powershell
New-NMMAccountsByAccountIdBackupRestore -AccountId <string> [-InputObject <object>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

POST /rest-api/v1/accounts/{accountId}/backup/restore
