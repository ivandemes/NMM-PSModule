# Set-NMMUamPolicyByIdDeactivate

## Synopsis

Deactivate MSP app deployment policy.

## Syntax

~~~powershell
Set-NMMUamPolicyByIdDeactivate -Id <integer> [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

PUT /rest-api/v1/uam/policy/{id}/deactivate
