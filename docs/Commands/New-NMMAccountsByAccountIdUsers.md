# New-NMMAccountsByAccountIdUsers

## Synopsis

Get a paginated list of users for the account.

## Syntax

~~~powershell
New-NMMAccountsByAccountIdUsers -AccountId <string> [-InputObject <object>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

POST /rest-api/v1/accounts/{accountId}/users
