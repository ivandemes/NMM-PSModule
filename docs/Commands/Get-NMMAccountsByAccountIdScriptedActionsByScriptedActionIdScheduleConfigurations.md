# Get-NMMAccountsByAccountIdScriptedActionsByScriptedActionIdScheduleConfigurations

## Synopsis

Get Azure runbook account scripted action schedule configurations.

## Syntax

~~~powershell
Get-NMMAccountsByAccountIdScriptedActionsByScriptedActionIdScheduleConfigurations -ScriptedActionId <integer> -AccountId <string> [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

GET /rest-api/v1/accounts/{accountId}/scripted-actions/{scriptedActionId}/schedule-configurations
