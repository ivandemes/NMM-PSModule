# Get-NMMAccountsByAccountIdGroupsByGroupId

## Synopsis

Get details of a group by group identifier.

## Syntax

~~~powershell
Get-NMMAccountsByAccountIdGroupsByGroupId -GroupId <string> -AccountId <string> [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

GET /rest-api/v1/accounts/{accountId}/groups/{groupId}
