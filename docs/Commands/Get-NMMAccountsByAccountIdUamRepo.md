# Get-NMMAccountsByAccountIdUamRepo

## Synopsis

Get list of repos managed at Account level.

## Syntax

~~~powershell
Get-NMMAccountsByAccountIdUamRepo -AccountId <string> [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

GET /rest-api/v1/accounts/{accountId}/uam/repo
