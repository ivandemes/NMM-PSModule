# Remove-NMMAccountsByAccountIdUsersByUserId

## Synopsis

Delete a user from Entra ID or Active directory by user identifier.

## Syntax

~~~powershell
Remove-NMMAccountsByAccountIdUsersByUserId -UserId <string> -AccountId <string> [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

DELETE /rest-api/v1/accounts/{accountId}/users/{userId}
