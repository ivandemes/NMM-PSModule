# Remove-NMMAppRoleAssignments

## Synopsis

Unassign app role from principals.

## Syntax

~~~powershell
Remove-NMMAppRoleAssignments [-InputObject <object>] [-Connection <psobject>]
~~~

## Description

## Notes
- PrincipalIds: a list of principals IDs to unassign app role from.

## API operation

DELETE /rest-api/v1/app-role-assignments
