# Get-NMMUamRepoPrivateOrphan

## Synopsis

List Msp linkable private winget repositories

## Syntax

~~~powershell
Get-NMMUamRepoPrivateOrphan [-Filter <object>] [-Connection <psobject>]
~~~

## Description

## Notes
Returns list of web applications available to be linked as private winget repository on MSP level

## API operation

GET /rest-api/v1/uam/repo/private/orphan
