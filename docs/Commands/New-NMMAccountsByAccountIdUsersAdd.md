# New-NMMAccountsByAccountIdUsersAdd

## Synopsis

Create a new user in Entra ID or Active directory.

## Syntax

~~~powershell
New-NMMAccountsByAccountIdUsersAdd -AccountId <string> [-InputObject <object>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

POST /rest-api/v1/accounts/{accountId}/users/add
