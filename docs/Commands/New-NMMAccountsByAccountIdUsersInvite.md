# New-NMMAccountsByAccountIdUsersInvite

## Synopsis

Invite a new user into the account as a guest user in Entra ID, and optionally send an invitation email.

## Syntax

~~~powershell
New-NMMAccountsByAccountIdUsersInvite -AccountId <string> [-InputObject <object>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

POST /rest-api/v1/accounts/{accountId}/users/invite
