# Get-NMMAccountsByAccountIdInheritedVariables

## Synopsis

Get a list of account inherited variables

## Syntax

~~~powershell
Get-NMMAccountsByAccountIdInheritedVariables -AccountId <string> [-Filter <object>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

GET /rest-api/v1/accounts/{accountId}/inherited-variables
