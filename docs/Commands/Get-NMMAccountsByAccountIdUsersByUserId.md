# Get-NMMAccountsByAccountIdUsersByUserId

## Synopsis

Get details of a user by user identifier.

## Syntax

~~~powershell
Get-NMMAccountsByAccountIdUsersByUserId -UserId <string> -AccountId <string> [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

GET /rest-api/v1/accounts/{accountId}/users/{userId}
