# Get-NMMInvoices

## Synopsis

## Syntax

~~~powershell
Get-NMMInvoices [-PeriodStart <string>] [-PeriodEnd <string>] [-HidePaid <boolean>] [-HideUnpaid <boolean>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.
