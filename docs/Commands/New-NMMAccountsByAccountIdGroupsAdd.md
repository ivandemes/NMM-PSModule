# New-NMMAccountsByAccountIdGroupsAdd

## Synopsis

Create a new group in Entra ID or Active Directory.

## Syntax

~~~powershell
New-NMMAccountsByAccountIdGroupsAdd -AccountId <string> [-InputObject <object>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

POST /rest-api/v1/accounts/{accountId}/groups/add
