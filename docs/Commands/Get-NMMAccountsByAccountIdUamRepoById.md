# Get-NMMAccountsByAccountIdUamRepoById

## Synopsis

Get Account level repo by ID.

## Syntax

~~~powershell
Get-NMMAccountsByAccountIdUamRepoById -Id <integer> -AccountId <string> [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

GET /rest-api/v1/accounts/{accountId}/uam/repo/{id}
