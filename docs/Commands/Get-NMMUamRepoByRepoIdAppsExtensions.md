# Get-NMMUamRepoByRepoIdAppsExtensions

## Synopsis

Get application extensions.
Extensions include app detection and auto-import configuration.

## Syntax

~~~powershell
Get-NMMUamRepoByRepoIdAppsExtensions -RepoId <integer> [-PackageId <string>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

GET /rest-api/v1/uam/repo/{repoId}/apps/extensions
