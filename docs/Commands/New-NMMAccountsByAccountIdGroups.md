# New-NMMAccountsByAccountIdGroups

## Synopsis

Get a list of groups for the account.

## Syntax

~~~powershell
New-NMMAccountsByAccountIdGroups -AccountId <string> [-InputObject <object>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

POST /rest-api/v1/accounts/{accountId}/groups
