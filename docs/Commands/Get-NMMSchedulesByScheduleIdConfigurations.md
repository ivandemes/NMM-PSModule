# Get-NMMSchedulesByScheduleIdConfigurations

## Synopsis

Get the list of related schedule configurations by global schedule profile id

## Syntax

~~~powershell
Get-NMMSchedulesByScheduleIdConfigurations -ScheduleId <integer> [-Connection <psobject>]
~~~

## Notes
- Id: Schedule profile id.

## API operation

GET /rest-api/v1/schedules/{scheduleId}/configurations
