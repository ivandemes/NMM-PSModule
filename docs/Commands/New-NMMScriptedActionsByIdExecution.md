# New-NMMScriptedActionsByIdExecution

## Synopsis

Run Azure runbook msp scripted action in Automation account.

## Syntax

~~~powershell
New-NMMScriptedActionsByIdExecution -Id <integer> [-InputObject <object>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

POST /rest-api/v1/scripted-actions/{id}/execution
