# New-NMMAccountsByAccountIdScriptedActionsByIdExecution

## Synopsis

Run Azure runbook account scripted action in Automation account.

## Syntax

~~~powershell
New-NMMAccountsByAccountIdScriptedActionsByIdExecution -Id <integer> -AccountId <string> [-InputObject <object>] [-Connection <psobject>]
~~~

## Description

No additional description is provided by the API specification.

## API operation

POST /rest-api/v1/accounts/{accountId}/scripted-actions/{id}/execution
